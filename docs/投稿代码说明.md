# 代码胶囊与这次仓库更新

代码胶囊可以理解为“别人打开就能运行的论文计算包”。它把程序、输入数据、依赖的软件版本和运行入口放在一起，审稿人不必自己重新配置整套环境。GitHub 主要保存代码和修改记录；Code Ocean 还提供在线执行与保存计算环境的能力。

Nature Communications 要求把支撑主要结论的自定义代码提供给编辑和审稿人。Code Ocean 是期刊提供的可选途径，不是唯一途径。你截图中的两道题不同：第一道是有没有开发核心代码，这篇文章应选“是”；第二道是愿不愿使用 Code Ocean 的支持服务，可以按你的分享计划选择。

## 具体操作

1. 如果采用 Code Ocean，在投稿系统第二道题选择“是”，按后续提示创建私人胶囊。也可以先整理并上传代码包，再按期刊要求提供审稿链接。
2. 从 GitHub 导入当前仓库，或上传本次整理包。胶囊使用 `code/` 中的程序和 `data/` 中的数据；旧版工作流文件夹已经从当前版本移除。
3. 选择 Python 3.12 环境，安装 `environment/requirements.lock.txt` 中的依赖。把 `code/run` 设为运行入口。
4. 点击 **Reproducible Run**，确认计算完成，并检查 `results/` 中的模型比较表、回溯结果图及运行记录。首次在平台上运行仍须实际检查，本机测试通过不能替代这一步。
5. 使用私人审稿链接提供给期刊；接受发表后，按平台与期刊流程发布最终版本并获得 DOI。现在还没有创建胶囊或 DOI，不要提前写成“已公开可用”。

## 本次代码的三个部分

- 默认运行描述符回归与回溯评估。后者在 101 个已有实测组分中模拟逐步查询，不产生新的实验数据。
- 原来的离线新组分推荐作为单独的可选功能保存，并标注“尚未实验验证”。它不进入默认论文复现流程。
- 原始工作簿和当前复现所需的参考 CSV 保留，旧版程序及其输出文件夹已移除。当前文件明确区分“参考结果”“本次重算结果”和“仅重新绘图”。

本次验证结果及其局限见 [validation.md](validation.md)。图文待核对事项见 [manuscript_alignment.md](manuscript_alignment.md)。仓库更新没有替你修改论文中的实验数值。

## 投稿系统文本框可填写的计划

以下是准备采用 Code Ocean 时的计划文字；胶囊创建成功后，再补上实际私人审稿链接并调整时态。

> The custom Python code and input data underlying the machine-learning analyses will be provided to the editors and reviewers. We plan to share a private Code Ocean capsule containing the descriptor-model workflow, the retrospective sequential-search benchmark, pinned software dependencies, and a reproducible run script. The final code and data will be made publicly available upon publication, with an archived version linked in the Code availability statement.
